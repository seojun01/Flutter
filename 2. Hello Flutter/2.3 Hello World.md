
### Widget
- 위젯은 레고블럭이라고 생각하면 됨.
- flutter에 있는 모든 것들은 Widget이기 때문에 레고블럭을 조립한다고 생각하면 됨.

### Making a Widget
- Widget을 만든다는 것은 class를 만든다는 것과 같음.
```dart
void main() {
	runApp(App());
}

class App extends StatelessWidget{
	@override
	Widget build(BuildContext context) {
		return MaterialApp(
			home: Scaffold(
				appBar: AppBar(title: Text("Hello flutter")),
				body: Center(child: Text("Hello, World")),
			), // Scaffold
		); // MaterialApp
	}
}
```
- #### Widget 이 되려면 flutter SDK에 있는 core Widget 중에 하나를 상속 받아야 함.
	- => StatelessWidget을 상속 받음.
	- => 상속 받기 위해 build 메소드를 구현함.
	- => build 메소드는 BuildContext 타입의 context라는 파라미터 받아옴.
- #### Widget Return 해주기
	- ##### 모든 앱은 CupertinoApp 또는 MaterialApp 중에 선택해야 함.
		- CupertinoApp : Ios 디자인 시스템
		- MaterialApp : Google 디자인 시스템
	- home: MaterialApp class의 속성
		- => scaffold라는 Widget 생성
		- => flutter 개발의 "화면이 scaffold를 가져와야 함"라는 규칙 때문에 모바일 앱의 모든 화면은 scaffold가 필요함.
			- => scaffold : navi bar, bottom tab bar, 상단 버튼, 화면 중앙 정렬 등
			- body 옵션 이용
				- => Text Widget으로 문자열 출력
			- appBar 옵션
				- => title 설정
