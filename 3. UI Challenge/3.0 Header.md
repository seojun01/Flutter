
### Column & Row
- Column은 가로줄이라고 생각하면 됨.
	- 위젯들을 가로로 같이 두고 싶을 때.
- Row는 세로줄이라고 생각하면 됨.
	- 위젯들을 세로로 같이 두고 싶을 때.
- Alignment
	- MainAxis : 수평(가로)방향
	- CrossAxis : 수직(세로) 방향

### SizedBox
- Size가 있는 box를 만들어줌. (padding 같은 느낌?)

### Text
- 텍스트에는 여러가지의 스타일이 적용 가능함.
- color
	- Colors.white 와 같이 사용
	- 컬러 코드로 사용하고 싶다면,
		- Color(0xFF181818) 과 같이 사용
- fontWeight
	- FontWeight.w800, 볼드체 같이 두께를 줄수 있음.
